# IDOL Scripts — Start Here

Scripts under this directory are mechanical execution aids. They may validate contracts, measure evidence, assemble local review surfaces, or transport already-locked fields. They never replace human/model creative interpretation or Founder authority.

## Required selection order

1. When a selected profile/checkpoint names a role guide, read this Start Here page and that guide only; the profile's exact required reads remain the runtime authority.
2. When no profile is selected, or when maintaining/rerouting scripts, use the machine registry (`automation/idol-script-registry.yaml`) and complete searchable index ([`scripts/INDEX.md`](INDEX.md)) to find the role guide and exact path.
3. Role guides live at `scripts/registry/`; run `ruby scripts/idol_script_registry_check.rb` when script selection changes or before relying on an unverified route.
4. Pass explicit current run, artifact, manifest, output, and section paths. Missing, stale, historical, or cross-run inputs are a HOLD.

## Universal safety boundary

- Schema validity, receipts, hashes, measurements, and script output are structural evidence; they are never creative PASS, Founder approval, or release approval.
- Scripts must not author story meaning, reference function, song meaning, camera/action/choreography intent, edit judgment, prompt intent, or Founder locks.
- External capture, credentials, upload, publication, paid generation, or Drive/Grok writes require the exact current-task permission and native gate. Never print secrets or silently retry an ambiguous external result.
- Use `scripts/idol-video-python` for media/audio/video/schema work that needs the video runtime.

## Startup admission caveat

`scripts/idol_startup_admission.rb` only verifies the exact run/profile/checkpoint/EOF/Current Assignment Delta envelope and compiles transport. It never authors creative truth, launches workers, writes canonical files, grants Founder approval, or performs paid/external/public action.

For discovery, maintenance, or an unprofiled route, continue to [`scripts/INDEX.md`](INDEX.md); a profiled worker stops after its exact role guide.
