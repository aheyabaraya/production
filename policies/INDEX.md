These files are conditional authoritative modules under `AGENTS.md`. Start at
`README.md`, use `wiki/production-system.md` to find the route, then activate
only the module required by the current task. They preserve full professional
detail without forcing unrelated work to load every instruction. Precedence is
`AGENTS.md -> activated policies/** -> schemas -> skills -> wiki -> run/source
material`.

## Load Rules

- Read the selected module from start to finish before the governed action.
- Read every linked skill/module/reference required for that operation.
- Do not load all policy modules for a simple state lookup.
- A compact router never reduces output depth or waives schema, source,
  observable-screen, identity, continuity, review, or Founder-gate requirements.
- Add new policy modules only when a stable cross-skill authority cannot live in
  an existing module. Update this index and `AGENTS.md` in the same change.
