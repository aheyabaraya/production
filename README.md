# IDOL

Public snapshot of the IDOL production loop. Source materials, contact sheets,
and yt-dlp tooling are not in this tree.

## Start Here

1. Read [`AGENTS.md`](AGENTS.md), the always-on authority kernel.
2. Open [`wiki/production-system.md`](wiki/production-system.md) to identify
   the current stage, owner, and return route.
3. Use [`policies/INDEX.md`](policies/INDEX.md) to activate only the policy
   required by the task; read that policy, its owning skill, schema, and linked
   modules to EOF.
4. Bind the current run, source hashes, permissions, and Founder decision state
   before writing. A delegated task creates its native Goal before required
   reads and uses the Department Dispatch Contract.

## Authority And Boundaries

Founder owns explicit locks, paid/external actions, final review, cleanup, and
release. Normal Founder gates are G0 direction, G1 planning, G2 draft keyframe
plus audio animatic, G3 reviewed section playback, and G4 final master/release.
One Overall Director lineage owns Founder conversation, promotion, and final
creative acceptance. After the verified Graph v2 switch, before G-40 a Planning CDD Cell of P1 Story/Audience, P2
Visual/Reference, and roster-derived P3-Ci Section/Kinetic lanes owns planning
review; after G-40 the same cohort ids continue as V-Ci Section-Cluster CDDs
through 02B pixel and 03V playback. Capacity never creates a cohort.
Until that switch the legacy-pinned route keeps one compatibility CDD and does
not co-run the Graph CDD lanes.
Performance readability is conditional. One separate Edit Director
owns 04 review/merge. Every artifact has one
active byte owner. Scripts validate transport and provenance, never creative
truth. After a verified atomic switch, new runs author through Graph Engineering;
historical `harness-*` ids remain parse-only Legacy Capsule inputs. External capture, download, upload, paid generation, and publication
need separate permission. When no image provider is named, the exact current
Grok CLI Section session uses only registered native `image_gen`/`image_edit`.
Cursor Luna image is explicit-only and opens only when the Founder names it;
its 03V owner transfer uses the registered eight-step CAS after pixel review. `gpt-image-2` is the only active OpenAI API
image model, xAI API requires explicit Founder selection, and no tool, auth,
model, event, or provider lane is silently aliased or used as fallback.

New non-media assignments prefer the exact run-resolved Grok CLI profile when
it is readiness-valid. 02B image generation defaults to the current Grok native
`image_gen`/`image_edit` lane; 03V video remains Grok CLI only. The Founder
briefing secretary uses Grok CLI `worker_high`. Cursor Opus, Fable, Sol, Luna,
and Gemini stay unused unless the Founder explicitly says to use that route
instead of Grok CLI. Any unavailable preferred route holds instead of silently
substituting another provider.
