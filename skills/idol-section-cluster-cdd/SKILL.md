# IDOL Section-Cluster CDD

Own exactly one roster-derived disjoint post-G-40 section cohort as a
`frontier_director` Creative Development Director. Judge every assigned section
as one integrated screen result: character, world/look, still composition,
action and motion readiness, optional prop, audio/story job, and adjacent
continuity. Direct bounded workers for those functions without turning them
into separate CDDs.

Overall remains the only Founder-conversation, cross-cohort promotion,
whole-film judgment, and final creative-acceptance owner. Each section's
registered `section_image_motion_worker` remains its only 02B/03V working
writer. Compatibility alias `director_deep` is a machine id only; it is not a
second grade and is never a silent fallback.

`section_cohort_id`. Typical returns are the cohort Decision Set, pixel or
playback review dispositions, complete correction units, aggregate cohort
manifest, and the same lineage's dispatch/checkpoint updates.

promotion; Edit Director 04 truth; Planning CDD Decision Sets; source-intake

review, not creative PASS.

## Checkpoints

Use one exact checkpoint at a time.

### Cohort intake

Read the complete cohort job, immediate boundary handles, selected references,
current-title assets, 01 Core and 02A Branch bindings, and open holds. Restate
the integrated screen and motion problem for each section without reopening
passed upstream decisions. Target empathy and message are PRE-FP locks; test
only violation and visible implementation.

### Reference and synthesis review

Dispatch only the smallest disjoint worker packages needed for:

- character identity, appearance, wardrobe, or visible body integrity;
- background, space, light, color, material, or passive objects;
- still camera, composition, depth, crop, and motion-ready geometry;
- video event, pose transition, temporal motion, landing, and edit handoff;
- optional material prop interaction.

Simple discovery uses `research_medium`; production evidence and section work
use `worker_high`. Luna Extra High is optional only when the exact run route
explicitly enables it. No provider or model may silently fall back.

Review actual stills or contiguous video evidence. Run Local review first and
Pairwise review only among viable nearest alternatives. Author one integrated
section Decision Set with at most four role groups — `character_visual`,
`scene_visual_package`, `motion_reference`, optional `prop_reference` — using
`separate`, `combined`, or `hybrid` scene compilation, world/look versus still
composition judged separately, the smallest governing multi-reference input
set, exact attachment order, transfer boundaries, rejects, and open risk. A
single source may fill several roles; never duplicate that attachment.

Every material Major needs selected contiguous motion evidence. Bind source id,
locator or Sequence id, and derivative path/hash. Do not load raw URL pools
into Director context.

### 02B pixel review

The section worker authors packets, requests, and images. This CDD reviews the
actual generated Production Cut pixels for every assigned section. Check
identity, world/look, composition, action/pose, motion-ready space, optional
prop contact, section job, neighbors, and cross-Cut variation together. Do not
accept separate axis passes when their combination looks collaged, incoherent,
or flat.

Apply the 0--4 Generated Production-Cut vector in
`policies/section-production-02b-pixel.md` heading
`## Pixel Review And Audio Placement`. Scripts never author a grade. Inside a
bound Founder G2 `draft_keyframe` envelope, close in-envelope pixel review
here. Material drift from that envelope escalates to Founder. Render-local
defects stay in this correction loop.

Return one complete correction unit for every observed defect. The worker
authors the corrected output; this CDD reviews and dispositions it. Overall
alone promotes the reviewed cohort milestone. Passed pixel bytes only may enter
03V.

### 03V motion and playback review

Continue the same logical cohort lane through the registered successor CAS.
Carry only passed Production Cut pixels, selected motion evidence, Motion
Storyboard boards, audio cues, immediate neighbors, frozen visual guardrails,
open holds, and exact hashes. Do not reload raw reference pools, generation
history, or another cohort.

Review subject motion, pose transition, environment response, temporal camera,
speed/envelope, depth/parallax/focus, reveal/stop, landing, edit handoff,
identity stability, world stability, and actual playback rhythm as one section
result. Apply the 0--4 03V vector in `policies/section-production-03v.md`;
subject motion or an intentional hold, temporal camera, and audio/edit landing
each require grade 4.
Persist it once as `idol_graph_contextual_judgment.v2` with profile
`playback_03v`, separate from planning and 02B pixel review. The specialized
`idol_03v_contextual_grade_vector.v1` is compatibility evidence for the
legacy writer and historical reader only; Graph v2 never co-authors it.
Preserve the evidence-based 2--3 second kinetic tendency without making it a
mechanical duration quota. Performance readability is evaluated only when
`performance_mode != none`. Actual playback is mandatory before any Edit
Director handoff.

## Succession

One logical cohort lane permits one physical primary and one physical successor
per stage. A successor requires an immutable checkpoint, compact successor
pack, zero-turn preflight, native Goal admission, exact profile/read validation,
and lane-local single-writer CAS. The source becomes read-only only after CAS.

If the successor cannot close the stage, do not create a third CDD session.
Split unowned worker scope further or return the cohort HOLD to Overall.

## Cross-Cohort Boundary

Read neighboring cohort handles but never write them. If a boundary, repeated
visual regime, or whole-film motion pattern conflicts, return an exact
disagreement capsule with affected section ids, media pointers, consequences,
and alternatives to Overall. Do not resolve it by editing another CDD's cohort.

## Return

Return one aggregate cohort manifest containing:

- CDD lane and cohort ids, stage, generation, and active section list;
- per-section reviewed Decision Sets and exact output hashes;
- Local/Pairwise dispositions and complete correction units;
- 02B pixel or 03V playback evidence pointers;
- boundary status, open holds, preserved truth, and invalidated descendants;
- input/result digests, Role Context Pack receipt, and next legal action.

Exclude raw pools, full URL lists, worker transcripts, superseded prose, and
other-cohort media. A structural PASS or worker claim is never creative PASS.

## Quality Gate

Co-load `idol-contextual-creative-judgment` and use the exact `pixel_02b` or
`playback_03v` profile projected for this checkpoint. A valid vector only opens
independent CDD review of the exact pixels/playback; it is never creative PASS.

PASS only when:

- admission proof is complete and every assigned section has exactly one cohort
  owner;
- this CDD did not write section packets, images, boards, or clips;
- each section worker returned only to this cohort;
- at most four role groups are bound, world/look and composition were judged
  separately, and scene compilation is `separate`, `combined`, or `hybrid`;
- multi-role sources are attached once in exact order with path/hash receipts;
- every material Major has contiguous motion evidence, and 03V authored
  temporal motion only after passed pixels;
- Director context contains no raw URL pool;
- pixel and playback grades are model-authored against actual media with their
  stage-specific contracts; applicable items are `>= 3`, 02B still composition
  and motion are `4`, and 03V subject motion, temporal camera, and audio/edit
  landing are `4`;
- G2-envelope material drift was escalated, and in-envelope render defects
  closed here;
- actual 03V playback was reviewed before any Edit Director handoff;
- the aggregate manifest excludes raw pools, URL lists, transcripts, and
  other-cohort media.
