# Professional Edit Decision Casebook (04)

Use this reference when choosing, disputing, or repairing a cut in 04. It owns
cut-reading craft, not 04FX realization. Read the passed source motion and the
selected audio together; never select a case by section label alone.

## Decision Evidence Protocol

For every incoming cut, inspect the rendered program at `-3, -2, -1, 0, +1,
+2, +3, +6` frames. Frame `0` is the first incoming program frame. Record:

- the selected-audio cue and the nearest actual onset, vocal entrance, stop,
  release, or section handoff
- the outgoing body/object/camera/gaze state at `-3..-1`
- the exact frame-zero composition and attention reset
- the incoming action, reaction, or intentional hold at `+1..+6`
- screen direction, eyeline, scale, subject placement, foreground/background
  depth, light, color, and object state across the boundary
- whether the viewer follows action, information, emotion, or deliberate
  contrast without an effect

Choose one timing relation:

- `anticipation`: cut before contact so the incoming shot owns the landing
- `exact_hit`: first incoming frame coincides with the audible/visible landing
- `afterbeat_hold`: outgoing result is held after the hit before attention moves
- `intentional_offbeat`: the gap or displacement is a stated story/performance
  choice and remains convincing on playback

An automatic marker may identify these frames. It cannot choose the relation or
pass the cut.

## Precision Hard Cuts And Action Timing

### Clean hard cut

- Signal: the outgoing endpoint and incoming first frame already make the
  musical and screen handoff legible.
- Pre/cut/post evidence: `-1` completes the outgoing state; frame `0` clearly
  changes owner, scale, or world; `+1..+3` immediately establish the new job.
- No-effect pass: yes. This is the default professional answer when it works.
- Send to 04FX only when a passed cut needs a restrained section signature;
  never because every boundary “needs a transition.”
- Return to 04 when frame `0` feels early/late, the incoming first useful frame
  is dirty, or the viewer cannot tell what changed.

### Cut on action — anticipation

- Signal: the outgoing shot begins a hand, foot, head, garment, camera, or
  object route; the incoming angle contains the readable landing.
- Pre/cut/post evidence: direction and speed are visible before the cut; frame
  `0` continues the same route; contact/landing happens after frame `0`.
- Story handoff: the incoming shot gains ownership of the action result.
- Fail symptom: the motion appears to repeat, teleport, or reverse direction.
- 04FX: usually none. A tiny accent may sign the later landing, not the cut.

### Cut on action — exact landing

- Signal: foot plant, formation lock, hand stop, gaze arrival, object closure,
  or camera stop meets a precise music marker.
- Pre/cut/post evidence: outgoing momentum is clear at `-2..-1`; frame `0`
  contains the arrival; `+1..+3` hold the result long enough to read.
- Fail symptom: the landing exists in both shots, or neither shot owns it.
- 04FX: a passed landing may receive a sparse hit accent. If the accent makes
  it feel late, return to 04.

### Cut after the hit / afterbeat hold

- Signal: the viewer needs the reaction, pose endpoint, lyric consequence, or
  world state for several frames after the audible hit.
- Pre/cut/post evidence: the outgoing result remains readable after the marker;
  frame `0` moves attention only after that result has registered.
- Fail symptom: the cut feels sluggish because the held frame carries no new
  information, tension, or afterimage.
- 04FX: do not add an effect to justify dead air. Shorten or choose a stronger
  result frame in 04.

## Continuity And Match Families

### Eyeline match

- Signal: a visible look-off creates a question and the incoming shot answers
  it with a member, object, or space.
- Evidence: eye direction at `-2..-1`; target placement at frame `0`; distance
  and angle make the gaze relation plausible.
- No-effect pass: the gaze path is understood without text or flash.
- Return to 04 if the incoming target sits on the wrong side or appears before
  the gaze has formed.

### Screen-direction match

- Signal: body, vehicle, camera, garment, light, or object travel continues
  across the boundary.
- Evidence: left/right or depth direction, speed, and endpoint are traceable on
  both sides. Deliberate reversal must be named as contrast.
- 04FX: a whip/blur is eligible only when source motion already supplies the
  streak. It cannot manufacture direction from static faces.

### Graphic/composition match

- Signal: face, hand, circle, doorway, reflection, horizon, negative space, or
  formation occupies a related screen position or shape.
- Evidence: compare frame `-1` and frame `0` geometry, crop pressure, depth,
  brightness, and attention center.
- Fail symptom: similar objects exist but the viewer's eye must jump across the
  frame without a reason.
- 04FX: optional low light/grade signature after the match already passes.

### Object-state match

- Signal: one visible object changes owner, state, scale, or location while
  carrying story continuity.
- Evidence: outgoing object state is unambiguous; frame `0` preserves identity;
  `+1..+3` reveals the changed consequence.
- Return upstream if the object state needed for the story was never generated.
  Return to 04 if a different available source contains it.

### Motivated contrast / hard reset

- Signal: the video needs a declared break in world, scale, energy, color,
  relation, or viewer position.
- Evidence: outgoing state is complete; frame `0` is decisively different; the
  selected-audio cue supports the reset; `+1..+3` establish the new rule.
- No-effect pass: contrast reads as intention, not missing coverage.
- 04FX: a short dip/flash may sign a passed reset. Dissolving away the contrast
  weakens the choice.

## Story, Reaction, Reveal, And Negative Space

### Reaction cut

- Signal: the screen job is how a member, group, crowd, object system, or space
  receives the previous action.
- Evidence: the cause is readable before the boundary; frame `0` gives a clean
  recipient; micro-expression, gaze, body stop, or environment response changes
  in `+1..+6`.
- Fail symptom: the reaction arrives before the cause or repeats information
  the previous shot already completed.

### Reveal cut

- Signal: withheld member, object, formation, space, or consequence becomes the
  new attention owner.
- Timing options: anticipation for surprise; exact hit for declaration;
  afterbeat hold for dread or emotional consequence.
- Evidence: the outgoing shot creates a question; frame `0` answers or deepens
  it; camera scale/depth keeps the reveal readable.
- 04FX cannot rescue a reveal whose incoming first frame exposes the answer too
  early.

### Insert cut

- Signal: a hand, foot, object, screen, garment edge, reflection, or environment
  detail carries one indispensable cue or transition job.
- Evidence: the insert has a named audio cue, visible action/state, duration,
  and return path. It is not a spare pretty frame.
- Fail symptom: the insert interrupts body mechanics, identity ownership, or
  lyric comprehension without adding information.

### Negative-space / intentional hold

- Signal: silence, breath, absence, room state, or afterimage needs duration.
- Evidence: the composition gives the eye a stable place; environmental or
  micro-body change remains visible; the next cut has a motivated release.
- No-effect pass: stillness itself carries tension or resolution.
- Return to 04 if the hold is only a duration filler.

## Performance And Repeated-Hook Coverage

### Wide → medium → close performance route

- Use a wide shot when formation, footwork, spacing, or world scale is the
  section job; a medium when torso/hand phrase and member relation matter; a
  close shot when face, lyric ownership, gaze, or beauty memory is the job.
- Do not rotate scales mechanically. Cut only when the selected cue and visible
  performance information justify the attention move.
- Across the boundary, protect action phase: the incoming scale must not hide
  the foot/hand/formation event that motivated the cut.

### Chorus gate

- Signal: energy, formation, camera scale, object system, or member ownership
  materially opens at the chorus entry.
- Evidence: pre-chorus compression is visible; frame `0` makes the release
  larger or clearer; the first hook phrase remains readable after the cut.
- 04FX is eligible after this cut passes, but one strong gate is preferable to
  repeating the package on every internal hit.

### Repeated-hook variation

- Preserve the recognizable point phrase or story function while changing at
  least the locally motivated owner, scale, angle, spacing, object state,
  tension, or consequence.
- Match the same cue only when repetition is the intended memory device.
- Fail symptom: the second hook is a duplicate coverage loop with no new screen
  information, or variation obscures the hook identity.

## Montage, Discontinuity, And Retime Landings

### Montage compression

- Signal: several actions, locations, members, or object states must compress
  time while preserving a clear progression.
- Evidence: each cut advances one state; cue density supports the compression;
  repeated scale/direction is intentional; the last cut lands a readable
  consequence.
- Do not use equal-length slots as a montage rule. Let the visible state changes
  and selected-audio cue density determine length.

### Deliberate discontinuity

- Signal: jump, axis break, repeated pose, temporal skip, or spatial mismatch is
  the chosen feeling—not missing coverage.
- Evidence: the discontinuity repeats or resolves as a coherent grammar, and
  the viewer retains identity, song position, and attention.
- No-effect pass: the break reads cleanly on its own.
- 04FX should not decorate an accidental discontinuity into legitimacy.

### Speed-ramp landing

- 04 owns the ramp, sampling/flow method, source in/out, and landing frame.
- Evidence: motion accelerates/decelerates without duplicate-frame chatter,
  body warping, hand/foot discontinuity, or gaze snap; the endpoint meets the
  marker and holds long enough to read.
- 04FX may sign a passed endpoint. If a micro-freeze or zoom changes the perceived
  landing, return to 04 and relock the recipe.

## Source-Family Mismatch Routing

- Use grade/color pipeline when the action, identity, timing, geometry, and
  world all work but exposure, white balance, contrast, grain, or delivery
  metadata separates the sources.
- Use 04FX for a short passed seam or music-bound color accent after base grade
  is correct.
- Recut in 04 when source quality, camera motion, depth, body mechanics, first
  useful frame, or composition makes the mismatch structural.
- Return upstream when the required identity, action state, angle, or world
  continuity does not exist in the available source pool.

## 04 / 04FX / Upstream Routing Matrix

| Observation | Route |
|---|---|
| Cut and source motion already read cleanly | keep in 04; no effect required |
| Passed boundary needs a restrained transition/accent signature | send to 04FX |
| Cut feels early/late or action phase repeats/skips | return to 04 |
| Wrong source, dirty first frame, weak endpoint, geometry mismatch | return to 04 |
| Required story/action/identity/world state was never generated | return upstream |
| Tone metadata/grade mismatch with otherwise correct source | 04 grade/color pipeline, then optional 04FX seam |
| Effect changes perceived timing, crop, speed, or source choice | return to 04 and re-preview |

## Cut-Decision Record Skeleton

```yaml
incoming_cut_decision:
  method: cut_on_action
  timing_relation: exact_hit
  timing_offset_frames: 0
  pre_cut_evidence: "Outgoing boot descends at -2f and garment follows left-to-right."
  cut_frame_evidence: "Frame 0 shows the same boot planted on the kick; camera is lower and wider."
  post_cut_evidence: "+1..+3f hold the formation lock before the next hand phrase begins."
  story_attention_handoff: "Attention moves from solo intent to the unit accepting the move."
  screen_direction_or_composition: "Left-to-right momentum and center floor line remain continuous."
  no_effect_pass: true
  route: keep_04
  route_reason: "The landing already reads on music; an effect would compete with the formation."
```
