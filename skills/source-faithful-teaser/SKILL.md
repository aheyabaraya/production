# Source-Faithful Teaser

Use one compact workflow. Keep source truth visible and generate only when the
verified source cannot supply a necessary bridge.

## Required Reads

Read completely before authoring or reviewing:

1. `AGENTS.md`
2. `teaser/AGENTS.md`
3. `teaser/README.md`
4. The active run's current intake, source index, plan, board, and review files
   that exist

Load these only when activated:

- `policies/creative-production-constitution.md` for story, storyboard, prompt,
  edit, or Founder-facing creative authoring;
- `policies/harness-routing-and-sources.md` for public research, source capture,
  run ownership, or promotion into an IDOL stage;
- `policies/repository-media-security.md` for downloads, local media runtime,
  browser capture, external tools, secrets, or API inputs;
- `wiki/artifact-management-system.md` before creating a new durable artifact,
  media folder, handoff, mirror, or cleanup plan.

Do not load idol member, choreography, trend-radar, CF, social, or model-sharding
modules unless the current task explicitly activates their separate owner.

## 1. Resolve The Run And Locks

- Keep work under
  `runs/ALBUM_KEY/TITLE_KEY/TEASER_<CONTENT_KEY>_<NNN>/`.
- Reuse the active run when it exists. Do not create an empty project tree.
- Lock the exact work, medium, edition or season, protagonist, excluded
  characters, story start/end, spoiler boundary, output format, and review or
  release boundary.
- Lock one emotional through-line. Let supporting characters reveal what the
  protagonist lost, received, learned, or chose; do not make them co-leads by
  accident.
- Lock one existing recording by artist, title, version, duration, source, and
  analysis status. Do not create, rewrite, remix, cover, or regenerate music in
  this lane.

Keep unresolved locks explicit. Draft planning may continue around a held item
only when it cannot contaminate downstream source or edit decisions.

## 2. Establish Canon Before Visual Selection

- Start with Founder-supplied and local material.
- Use official or original sources to verify character identity, event order,
  relationships, dialogue, costume, weapon, and world effects. Use community
  summaries only as discovery maps.
- Separate verified fact, inference, contradiction, and unknown. Do not convert
  a plausible summary into a scene lock.
- Keep each supplied reference until it closes as `applied`, `combined`,
  `held`, or `rejected`, with the target scene/cut and reason.

If the needed source pixels are unavailable, hold the visual decision. Do not
invent from prose memory.

## 3. Select Actual Source Evidence

Assign one direct-use mode to every selected source:

- `direct_plate_use` for original pixels used in the edit;
- `direct_generation_reference` for a source attached to one optional bridge
  request;
- `direct_sequence_reference` for an ordered start, change, peak, and end
  sequence.

Record source identity, official locator, episode/chapter or time range, actual
local path, SHA-256, selected panel/frame/crop, pixel-inspection state, target
cut, and allowed use. Keep the original for provenance. Treat a contact sheet
as navigation evidence and pass only the selected derivative into downstream
visual work.

For direct scene or sequence following, preserve character identity, action,
expression and gaze, prop or weapon, effect, body route, camera geometry,
composition, and scene order. Apply only explicitly locked replacements or
format changes. Do not weaken a usable selected source into `function_only`
prose.

Do not add unrelated reference candidates merely to fill a quota. If the work
enters canonical 01R, use that stage's comparison floor and owner contract.

## 4. Build The Whole-Teaser Map

- Map the selected recording across the full intended teaser before extracting
  short derivatives.
- Progress the one emotion across the sequence; do not restate the same thesis,
  caption, symbol, or action in every cut.
- Give every cut one dominant screen job and an exact source locator, audio cue,
  visible event or intentional hold, subject identity, composition, camera,
  and previous/next handoff.
- Split only when story state, source scene, audio cue, action, gaze,
  composition, camera attention, object/world state, or edit handoff changes.
  Never split by equal seconds, prompt slots, or a fixed image count.
- Treat lyrics as a meaning guard unless an exact lyric is the audible turn. Do
  not republish lyrics or use them as default captions.
- Treat `AAA` as unresolved until an exact work or trailer is named. Apply it to
  motion, depth, sound, material weight, camera restraint, or finish quality;
  do not silently redesign the source character or art style.

Keep planning in `research/drafts/` until the Founder selects the edition,
scope, emotional route, song recording, and visual-use boundary. Promote only
the selected current plan into a durable run-owned research or review file.

## 5. Generate Only Missing Bridges

Generate only when no verified source can supply a continuity-critical bridge.
Bind one request to the selected source files, missing screen job, exact output
path, and adjacent cuts. If the execution surface cannot accept every required
source or parameter, hold instead of replacing the source with text.

Keep the result in the run, hash it, inspect the pixels, label it generated, and
review character identity, art grammar, action, camera, composition, and
continuity against the selected source before use. OpenAI image API requests
must use `gpt-image-2` and require current-task paid-generation approval.

## 6. Review Fidelity And Close The Package

Review the actual assembled playback, not only plans or file presence. Check:

- protagonist identity and supporting-character role;
- canon event order and story boundary;
- face, hair, body, clothing, weapon, prop, effect, and art-grammar continuity;
- direct-scene action, expression, camera, composition, and sequence fidelity;
- song-to-story progression and edit handoffs;
- source/generated classification, locators, hashes, and final-use trace;
- unofficial fanmade label, original-work and music credit, and release status.

Return a concrete pass, revise, or hold with the affected cuts and source
evidence. Preserve unaffected material. Do not infer download, generation,
external upload, publishing, or public-release approval from a creative pass.

## Promotion Boundary

This skill owns the compact teaser lane, not canonical IDOL stage readiness. If
the Founder promotes work into an existing IDOL stage, load that stage's owning
skill, schema, Department Dispatch Contract, and validator, then translate only
the selected source-bound truth. The dispatch must require the owning skill and
linked modules to EOF, bind runtime digests, and receive director review before
promotion; do not create a new manual skill receipt. Do not claim that a teaser draft has satisfied
Front Planning, 01R, 02A, 02B, 03V, 04, or 05 by file presence.
