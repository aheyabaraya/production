# Identity Guard Language (Copy-Paste Ready)

Use these blocks at the top of every prompt generated with this skill.

## Full Guard (Recommended for Grok Imagine)

```
Identity lock — absolute, zero tolerance:

Use the attached character-board.png as the definitive reference for:
- Face geometry (eye spacing, eye shape, jaw line, lip shape, face length, nose, brow)
- Body proportion (head-to-torso ratio, shoulder width, arm thickness, hand size relative to face)
- All three face angles (front, 3/4, side) must remain consistent with the board

Use the attached current clean face reference image as the approved:
- Lighting family (soft beauty, gentle volume, subtle glow)
- Expression baseline (gentle, approachable, soft smile or calm gaze)

Do not invent age, do not make the person look older or younger, do not compare to any real person.

Zero drift on:
- Eye spacing and eye shape
- Jaw line and face length
- Lip shape and mouth proportion
- Head-to-body ratio
- Skin undertone and overall face structure

If the generated result drifts in any of the above, it is rejected.
```

## Short Version (When Prompt Length Is Tight)

```
Strict identity lock: Match the attached character-board.png face angles and body proportions exactly. Match the attached clean face reference for lighting and gentle expression. No face drift, no proportion change, no original fictional identity.
```
