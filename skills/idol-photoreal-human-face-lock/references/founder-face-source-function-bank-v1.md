# Founder Face Source Function Bank V1

Use this reference when the founder asks to turn the 23 supplied face images
into original photoreal human face candidates. This is not a likeness bank. It
is a source-function bank: every source feature must be translated into new
visible morphology for fictional people.

Full analysis source:

- `source-materials/face-lock-references/photoreal-face-source-function-analysis-v1.md`

## Safety Boundary

- Do not use real names, filenames, source labels, third-party identity label targets,
  or "make this person" language in model-facing prompts.
- Follow the selected reference function and current-run locks; treat one reference wholesale as source provenance. Build each candidate from an abstract
  face architecture plus controlled deviations.
- Keep every candidate in the founder-locked age lane through internal safety
  notes, visible jaw/neck, real-camera texture, and identity-separation sourcing.
- For early-20s "beautiful girl" tests, use that exact positive age phrase in
  the model-facing prompt. Do not add `adult`, `woman`, or negative youth
  wording to that prompt; control the read with lower-face length, cheek
  fullness, brow softness, compact nose/mouth scale, and source face-plane depth.
- Do not use `idol`, `K-pop visual`, `perfect`, `flawless`, `porcelain`, or
  `beauty-filter` as face identity language.
- Avoid smooth AI skin. Every candidate needs pores on the nose/inner cheeks,
  under-eye tone variation, cheek-plane light breaks, lip texture, and flyaway
  hair or baby-hair irregularity.
- Depth and volume are mandatory. Every candidate must name eye-socket depth,
  upper/lower-lid shadow, nose root/bridge/tip/base projection, cheekbone and
  midface plane breaks, lip projection with philtrum/lower-lip shadow, chin
  projection, and jaw/neck cast shadow. A face that only lists outline and
  feature shape is not prompt-ready.

## Difference Axes To Preserve

For a candidate set, vary all five axes. Do not rely on hair color or makeup as
the only difference.

1. Face outline:
   - long refined oval
   - compact round oval
   - balanced clean oval with open forehead
   - narrow V-oval or inverse-triangle
   - short compressed oval
   - hair-frame-led asymmetry
   - smile/cheek-led face

2. Eye orbit:
   - large round eyes with high natural iris visibility and real socket depth
   - long low-lidded eyes with restrained vertical openness
   - big almond eyes with outer extension
   - smiling crescent eyes
   - one-eye or hair-covered asymmetry

3. Nose and midface:
   - narrow straight bridge with small rounded tip
   - short rounded central nose with soft midface
   - visible bridge/root light axis and stronger z-plane
   - low smooth bridge that requires side-plane shadow

4. Mouth and philtrum:
   - small centered mouth
   - fuller lower lip with real uneven highlight
   - slightly parted mouth
   - wide visible smile
   - soft closed smile

5. Hairline and face frame:
   - center-part long vertical frame
   - side curtain or one-side covered face
   - bangs or see-through fringe
   - short bob / cropped face frame
   - braid or one-sided decorative frame

## Eighteen Candidate Archetypes

These archetypes are reusable starting points for original people. They do not
name or target the source images.

### FH-01 Long Oval Almond / Short Philtrum

- Primary architecture: long egg-oval face with balanced thirds and a small
  rounded chin.
- Dominant memory point: large almond eyes with slight outer lift.
- Secondary memory points: narrow straight bridge with visible side-plane
  shadow; short philtrum with fuller lower lip.
- Distinctiveness pressure: preserve face length and nose shadow so this does
  not collapse into a small-nose idol average.
- Non-mirror topology: one cheek mark or tiny texture point; one lower lid
  brighter; one side has looser face-framing strands.

### FH-02 Compact Round-Eyed / Fringe Frame

- Primary architecture: compact round egg-oval with a short lower face.
- Dominant memory point: large round eyes with high natural iris visibility and
  real socket depth.
- Secondary memory points: short rounded nose; small parted mouth with a plump
  lower-lip center.
- Distinctiveness pressure: compact cheek and short chin, not a long V-line.
- Non-mirror topology: uneven fringe density; side wisps fall at different
  lengths; one lower lid has stronger cushion.

### FH-03 Smile-Cheek Crescent

- Primary architecture: soft heart-oval with open upper face and rounded lower
  face.
- Dominant memory point: smiling crescent eyes and lifted cheek planes.
- Secondary memory points: wide visible smile; one-side heavy hair curtain.
- Distinctiveness pressure: expression tissue and cheek lift, not static
  symmetrical beauty.
- Non-mirror topology: asymmetric smile line; one ear/cheek more exposed; one
  hair side heavier.

### FH-04 Long Low-Lidded Quiet Face

- Primary architecture: long narrow oval with visible negative face space.
- Dominant memory point: horizontally long low-lidded eyes.
- Secondary memory points: long thin nose bridge; small horizontal mouth.
- Distinctiveness pressure: restrained feature scale and low-lid calm gaze.
- Non-mirror topology: one inner hair strand enters the cheek line; eyelid
  crease heights differ slightly.

### FH-05 Bob-Framed Round Oval

- Primary architecture: stable round egg-oval, not sharply tapered.
- Dominant memory point: chin-length bob or blunt face frame that crisps the
  outline.
- Secondary memory points: large lined almond eyes; glossy but textured full
  lips.
- Distinctiveness pressure: bob-framed cheek width and soft short jaw.
- Non-mirror topology: uneven bang gaps; one bob end sits lower; one mouth
  corner rests a fraction higher.

### FH-06 Wet-Fringe Frontal Round Eyes

- Primary architecture: small long egg-oval with narrow lower face.
- Dominant memory point: large round frontal eyes under separated damp fringe.
- Secondary memory points: tiny rounded nose tip; small parted lips.
- Distinctiveness pressure: wet asymmetric fringe plus compact mouth/nose.
- Non-mirror topology: bang clumps differ; side strands cut the cheeks at
  unequal heights.

### FH-07 Slim Long Oval / Restrained Mouth

- Primary architecture: slim long oval with balanced thirds.
- Dominant memory point: long low-lidded almond eyes close to low straight
  brows.
- Secondary memory points: small restrained mouth; narrow straight nose.
- Distinctiveness pressure: quiet long oval and small mouth.
- Non-mirror topology: one side hair shadow is heavier; one eye opens slightly
  less.

### FH-08 Layered Midface Oval

- Primary architecture: slim egg-oval with slightly longer midface.
- Dominant memory point: rounded almond eyes paired with a longer narrow nose
  bridge.
- Secondary memory points: defined upper-lip line and fuller lower lip; layered
  hair wrapping one cheekbone.
- Distinctiveness pressure: longer midface and layered cheek frame.
- Non-mirror topology: three-quarter face width difference; one cheek is partly
  covered by layered hair.

### FH-09 Broad Forehead / Short Lower Face

- Primary architecture: very soft egg-oval with broad forehead and short lower
  face.
- Dominant memory point: large round eyes with low outer corners.
- Secondary memory points: low smooth bridge with side-plane realism; central
  plump lips.
- Distinctiveness pressure: broad forehead plus short lower face, guarded
  against doll/anime smoothing.
- Non-mirror topology: diagonal hairline division; one small cheek texture
  point; one lower lid softer.

### FH-10 Cheek-Volume Closed Smile

- Primary architecture: round egg-oval with stable cheek-to-jaw transition.
- Dominant memory point: soft cheek volume carrying a closed or slight smile.
- Secondary memory points: bright rounded almond eyes; medium lips with lifted
  corners.
- Distinctiveness pressure: fuller cheeks and non-severe jaw.
- Non-mirror topology: one cheek catches stronger light break; hair volume
  differs left/right.

### FH-11 Clean Oval / Small Features

- Primary architecture: balanced clean oval with open forehead.
- Dominant memory point: restrained feature scale across eyes, nose, and mouth.
- Secondary memory points: natural almond eyes; small soft mouth.
- Distinctiveness pressure: clean empty face space, not enlarged idol features.
- Non-mirror topology: one side long hair covers more cheek; one ear or jaw side
  is more open.

### FH-12 Narrow V-Oval / Strong Eye-Lip Contrast

- Primary architecture: narrow V-oval tapering quickly below the cheekbone.
- Dominant memory point: large almond eyes with outward extension.
- Secondary memory points: visible straight nose bridge; fuller lower lip with
  real texture.
- Distinctiveness pressure: V taper plus stronger z-plane, but use less glamour
  styling than the source family to avoid likeness.
- Non-mirror topology: uneven bang or hairline density; one side loose strand;
  chin endpoint slightly off center.

### FH-13 Long Nose-Axis Vertical Frame

- Primary architecture: long balanced oval with narrow lower face.
- Dominant memory point: long straight nose axis inside a vertical hair frame.
- Secondary memory points: big almond eyes; small balanced lips.
- Distinctiveness pressure: long nose/midface order and off-center hair part.
- Non-mirror topology: one hair side heavier; eye outer corners differ subtly.

### FH-14 Short-Hair Asymmetry

- Primary architecture: small oval with modest cheek-to-jaw width difference.
- Dominant memory point: short bob or cropped side strands around the temples.
- Secondary memory points: long calm eyes; small slightly parted mouth.
- Distinctiveness pressure: hair-frame asymmetry and long eyes, not a generic
  face outline.
- Non-mirror topology: one side strand lower; one mouth corner softer; one eye
  partly shadowed.

### FH-15 Short Compressed Oval / Open Eyes

- Primary architecture: short oval with compressed midface and lower face.
- Dominant memory point: wide-open eyes with clear inner and outer corners.
- Secondary memory points: small smooth nose tip; short philtrum and softly
  parted mouth.
- Distinctiveness pressure: short midface, small mouth, and rounded V chin
  before any styling.
- Non-mirror topology: one braid or side strand changes outer balance; opposite
  neck/shoulder side is more open.

### FH-16 Strong-Nose Restrained-Eye Editorial Face

- Primary architecture: medium-long soft square-oval with a visible jaw corner
  that exists but stays natural.
- Dominant memory point: stronger nose z-plane with visible root, bridge side
  planes, projected tip, and readable base shadow.
- Secondary memory points: restrained almond eyes set slightly deeper under the
  brow; small matte mouth with a longer philtrum.
- Distinctiveness pressure: nose/midface depth and natural jaw, not large-eye
  beauty averaging.
- Non-mirror topology: nose axis sits a fraction off center; one nostril wing
  is more shadowed; one jaw corner catches less light.

### FH-17 Broad-Cheek Wider-Jaw Human Face

- Primary architecture: broad cheek-oval with a wider natural jaw path and short
  rounded chin.
- Dominant memory point: cheek and jaw volume, including visible cheek-plane
  light breaks and a natural jaw corner.
- Secondary memory points: smaller compact eyes with clear lower-lid volume;
  medium-width relaxed mouth.
- Distinctiveness pressure: wider human jaw and cheek mass, not a narrow
  V-line.
- Non-mirror topology: one cheek plane is brighter; one mouth corner rests
  lower; hairline is more open on one temple.

### FH-18 Asymmetric Mouth-Chin / Low-Lidded Face

- Primary architecture: long lower-face oval with a specific chin endpoint
  slightly off the exact centerline.
- Dominant memory point: asymmetric mouth and chin topology.
- Secondary memory points: low-lidded eyes with one flatter lid and one rounder
  lid; medium nose bridge with visible tip projection.
- Distinctiveness pressure: off-center lower-face structure and non-mirror
  mouth behavior, not symmetrical idol polish.
- Non-mirror topology: one mouth corner is higher without a smile; philtrum
  groove leans slightly; chin endpoint and nose base do not align perfectly.

## Set Construction Rule

For an 18-person board, use all 18 archetypes once before repeating any
architecture. If a generated result drifts toward the same averaged face,
rewrite the next prompt by changing face outline first, then eye orbit, then
nose z-plane, then mouth/philtrum, then cheek/jaw depth, then hair frame.
