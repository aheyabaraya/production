# CDD-P2 Visual/Reference Development

Use this mode for the pre-G-40 visual regime, identity, and reference Decision
Set. It judges evidence and transfer; it does not own storyline integration,
section topology, 02B generation, or 03V playback.

## Own

- official/original source eligibility and bounded Pinterest/video discovery;
- current-title character visual and wardrobe direction;
- world/look, light, material, still-camera and composition evidence;
- motion evidence coverage and optional hero-prop evidence;
- applied/combined/held/rejected dispositions and source-to-screen deltas;
- the smallest governing reference set for each named planning need.

Keep at most four production role groups: `character_visual`,
`scene_visual_package`, `motion_reference`, and optional `prop_reference`.
Within `scene_visual_package`, evaluate `world_look_binding` and
`composition_anchor` separately before checking their visual compatibility.
A title-global background/world package remains forbidden. A section- or
Cut-scoped `scene_visual_package` is a reference role, not a second canonical
world owner.

Wardrobe belongs inside `character_visual`. It is not a separate score.

## Optional Performance

Performance readability is not a standing criterion. Activate it only when
`performance_mode` is `supporting` or `primary` and actual performance evidence
exists. When `performance_mode` is `none`, retain one explicit
`not_applicable` criterion row with the exact reason. Do not
invent a performance reference to avoid an N/A.

## Review

Inspect actual stills, exact derived frames, or contiguous motion intervals.
Pinterest is strongest for still styling, pose, space, light, and composition;
registered official/original video sources are strongest for body transition,
camera behavior, landing, and edit rhythm. Platform does not determine function.

Keep source shape and screen function separate in every survivor: `media_type`
or `media_kind` says image/video/range/frame/crop/board, while the selected
purpose says background/space, light/material, still camera/composition,
pose/action, object/environment response, or edit/transition. A media token is
never a function. Exact-carry the applied/combined reference unit and function
pointers/hashes into the 02B logical-role plan.

One source may fill multiple roles and must be registered once. Do not enforce
multiple applied references when one governing source closes the screen need.
When more than one applied or combined unit is retained and a distinct
relevant eligible alternative exists, do not draw the extra unit from the
same work, the same event, and the same visual grammar. Name provenance,
event, camera height and direction/angle, composition, and screen function
from the existing unit fields. Shot-size-only or function-label-only
differences do not count as variety. An explicit Founder-direct lock that
requires the repeat is a named HOLD, not a discretionary exemption.
Reject collage, accidental identity transfer, unauthorized copying outside
the selected transfer scope, and reference sets that cannot survive combined
image synthesis. Authorized direct-follow remains subject to its selected
scope and current-title identity locks.

Grade the P2 reference Decision Set on the 0--4 scale. Every material
Major's selected contiguous motion evidence and still-camera/composition
evidence must each reach grade 4 before promotion eligibility. Use the
`reference_candidate` profile of `idol_graph_contextual_judgment.v2` selected by
the exact P2 Role Context Pack. P1 and P3-Ci separately apply
`front_planning_close` when they integrate the G-40 handoff and section/kinetic
architecture; P2 never authors that profile. Do not mix either planning profile
with the downstream Production-Cut pixel rubric. The older planning vector is
legacy-pinned only. Grade 3 may combine or correct internally. Grades 0--2 stay
out of Founder projection.

Return compact source ids, derivative paths/hashes, locators, functions,
dispositions, transfer boundaries, and selected visual evidence. Keep URLs in
the source manifest rather than repeating them in downstream context.
