### Noncanonical good / bad teaching examples

These examples teach shape only. They are not creative truth and must not be
copied into a run.

Bad (reject — mood/function only):

```text
This reference has tense isolation, cinematic pressure, and strong
major-scene grammar for the chorus.
```

Bad (reject — top labels only, no nested leaves):

```text
Identity reference rule: source person
Scene intent: cold hallway scene
Visible details: cinematic framing
Action cue: standing
Avoid: copy the face
```

Bad (reject — whole sheet as one still mood):

```text
The contact sheet feels cold and editorial; use it as the visual world.
```

Bad (reject — sheet with only one nested tree and no flow):

```text
Identity reference rule: ...
Scene intent: the sequence is dynamic
Visible details: ...
```

Good still shape (Lane 1; fill every bracket from the current selected surface):

```text
Identity reference rule:
  source_cast_or_subject: [who/what in the source pixels]
  current_title_member_visual: not_attached
  identity_guard: source face/body is not Loom identity
Scene intent:
  who_or_what: [primary subject or object system]
  where: [exact place type proved by pixels]
  single_event_or_hold: [one recognizable event or hold]
Visible details:
  background_and_space: [space facts]
  still_camera_and_composition:
    camera_height: [height]
    shot_scale_distance: [scale + distance]
    direction_angle: [direction + angle]
    depth_design: [fg / mg / bg]
    subject_placement: [frame placement]
    crop_negative_space: [crop + open space]
    lens_feel: [perspective character]
  lighting_color_material: [light, color, material facts]
  face_gaze_when_visible: [gaze/expression or none]
Action cue:
  subject_state_or_pose: [pose/state]
  visible_action_or_hold: [action or hold]
  object_environment_response: [response or null]
Avoid:
  do_not_transfer: [source face as title identity; unselected sheet cells;
    named discard traits; mood-only paraphrase]
```

Good sheet shape (Lane 2 skeleton):

```text
Sequence flow observation:
  sheet_role: navigation_and_ordered_grammar_only
  continuous_event: [one event across cells]
  ordered_phase_route:
    - phase: start
      cell_or_frame_locator: [cell A]
      what_is_happening: [entry state]
    - phase: change
      cell_or_frame_locator: [cell B]
      what_is_happening: [visible turn]
    - phase: peak_or_end
      cell_or_frame_locator: [cell C]
      what_is_happening: [release, impact, or hold]
  what_stays_continuous: [named carriers]
  what_changes_across_cells: [named per transition]
  ordered_scene_grammar: [follow phase order; entry -> exit]
  selected_anchor_cells:
    - cell_locator: [cell A]
      selection_reason: [still/02B or motion start anchor]
    - cell_locator: [cell C]
      selection_reason: [still/02B or motion end anchor]
  unselected_cells_policy: navigation_only_do_not_bind_or_attach
Then: write one full Lane-1 nested tree for each selected_anchor_cells entry.
```
