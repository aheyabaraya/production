# IDOL Front Planning Director

Use this skill when the Founder supplies a short brief, selected song, main and
support references, or an incomplete scene direction and expects the studio to
expand it into a reviewable MV plan with minimal intervention.

Until a verified Graph v2 switch receipt exists, this skill is the
legacy-pinned one-CDD Front Planning owner through 03V as `AGENTS.md` states.
After that switch it is the Planning CDD Cell's reviewed Decision Set consumer
and G-40 handoff integrator. Lane authoring uses `skills/idol-planning-cdd` in
P1 Story/Audience, P2 Visual/Reference, and roster-derived P3-Ci Section/Kinetic
modes. This skill does not write another lane's Decision Set. It integrates
P1-linked survivors, quality-checks the Front Planning artifact, directs bounded
logical `worker_high` departments through the run-resolved registered provider
when a remaining named gap belongs to this consumer, reviews every return, and
exposes the review cycle on the single Founder workbench. The Planning Cell never
promotes canonical truth; the Overall Director alone promotes the recommendation, requests Founder decisions, and owns final creative acceptance.

## Planning Method

### 0. Lead The Director-Room Draft Loop

When the Founder brief is a premise, reference bundle, ingredient list, or
partial scene order, do not begin by asking the Founder to complete planning
fields. Following `wiki/director-room-sequence-discovery.md`, the Creative
Development Director offers the first rough screen sequence from the selected
song, supplied references, actions, objects, spaces, relations, performance
ideas, and sound opportunities.

Audit that sequence aloud for pacing, overloaded or idle members, repeated
screen carriers, reference-order loss, visual misread, missing message, sound
opportunity, and entry/exit continuity. Translate any ordinary corrections the
Founder chooses to give, such as
"this is too long", "one member does everything", or "there is no message"
into structural revisions, then return the complete affected flow rather than
only the changed beat. Do not require a separate sequence-approval conversation:
the Creative Development Director's complete recommended flow proceeds to the
Overall Director for promotion unless a material exception must be resolved.

Transcribe the conversation into a separate `Founder Sequence Control` file
using `schemas/idol-founder-sequence-control.schema.json`. The Founder does not
fill the schema. A short direction, selected song and references, one must-have
or avoid, or an explicit request for the first proposal may authorize the
start. Bind the Overall Director's exact startup input and initial Founder
Kernel candidate; do not infer a lock that is absent from both. The Creative
Development Director drafts the compact whole flow,
reference-role proposals, locks, forbids, and conflict analysis for Overall
Director review. The control becomes `director_ready`
when startup is authorized, projection is allowed, and no material start
conflict remains; it is not a separate Founder PASS gate.

First exact-project the v4 PRE-00 handoff's entire `storyline_lineage`: original,
active full text, revisions, density review, and reference functions/exclusions.
Then project the director-ready control into `founder_brief`,
`target_message_lock`, `whole_film_spine`, `section_plan`, Major directions, and
exact reference assignments. In `target_message_lock`, preserve the
Founder-locked PRE-00 target and audience promise while authoring the message
and observable screen response. The control is an input contract, not a new
stage, fixed beat count, or substitute for the full PRE-00 storyline, song
evidence, reference inspection, audience work, member visuals, Direction
Alignment, or 02A Final Planning.

### 1. Read The Song Against The Locked Audience Promise

Identify:

- exact Founder-locked PRE-00 primary target, audience promise, and do-not-serve rules;
- selected-song listener evidence and standing K-pop baseline as a fit test, not a replacement target;
- message, attitude, desire, conflict, or emotional result;
- lyric/audio turns that seed, complicate, release, resolve, or withhold it;
- the screen reward the viewer should receive;
- do-not-serve rules and likely rejection triggers.

Keep evidence, inference, contradiction, unknowns, and Founder decisions
separate.

### 2. Verify Fit And Translate The Lock

Read the PRE-00 target connections, evidence, counterevidence, trend synthesis, and content contract. Test whether the selected song and reference anchors can deliver that already locked reward.

Validate:

```text
target
-> response mechanism
-> observable screen translation
```

Do not select another target here. Do not re-score `target_empathy_fit` or
`message_fit`. Ask only whether the result violates the PRE-FP lock or fails
to realize it as observable action, space, or state change. Translate the
fixed target into the MV message, whole-video content roles, observable
screen consequences, and connection-and-role-bound reference searches. If the
song materially cannot serve the lock, revise or reject it; reopen PRE-00
only when the Founder explicitly changes the target.
