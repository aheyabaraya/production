# Pinterest Section Comparison Detail

Use this module only with the registered Pinterest Visual/Composition worker.
It defines the evidence depth for one section cohort; it does not choose a
creative direction.

## Search Brief

Before discovery, write one row per section with:

- aligned whole-video and section job;
- existing Sequence evidence and the named distinctive still gap Sequence
  does not carry (cloth, crop, gesture, space fragment, light, silhouette);
- existing governing and supporting references;
- missing or challenged screen function;
- acceptable main/support contribution;
- member-identity, source, continuity, and feasibility boundaries;
- the Major, Key Screen, or likely Core-Cut decision this comparison must help.

Sequence owns the event. Pins are distinctive non-event stills, not Sequence
Units. A look pin is not the event. First query is one visual kernel for that
named gap. Do not query storyline paragraphs, lyric paraphrases, or camera
essays.

One dispatch may contain several sections, but candidate ids, image paths,
contact-sheet groups, and RWI rows remain section-separated. Process cohorts in
order; do not blend a visually convenient pin across sections without an
authored role and independent comparison in each affected section.

## Ordered Discovery Passes

### Pass A — `kernel_search` (`pose_ignition` when the gap is gesture)

Name the distinctive gap Sequence does not carry. First query: one visual
kernel — one observable noun or pose — for that gap. `pose_ignition` is that
kernel when the gap is gesture or relation: body level, axis, balance, lean,
twist, reach, fold, recoil, suspension, grounded contact, hand/limb route,
gaze relation, touch or avoidance, group relation, and subject-object or
subject-architecture interaction. A single garment noun is the kernel when the
gap is cloth. For a non-human or environment-led gap, use one object, material,
space fragment, or light kernel.

Do not query storyline paragraphs, lyric paraphrases, or camera essays. Do not
overload the first query with a complete camera prescription. Camera is read
from the chosen pin after inspection, never loaded into the first query. Pose
is a discovery ignition for a gesture gap, not identity evidence,
choreography, a member-direction lock, or downstream 02A pose truth.

If the named gap is still open after pixel inspection, second query: add one
noun or pose only. Kernel-only search with no second-term follow-up is a HOLD
while that named axis remains missing. If the gap is closed, stop. Do not
stack a third term or a sentence.

### Pass B — `camera_composition_extraction`

After individual pixel inspection, extract how the observed pose/action/relation
or still fragment creates or benefits from camera height, distance, direction,
angle, axis, lens/depth behavior, placement, crop, negative space, occlusion,
foreground/background relation, and lead/reveal room. Name what becomes
visually useful because of that relation and what is lost if it is removed.
Camera/composition observations must come from the inspected candidate; they
are not invented from captions, keywords, or a fully predetermined query.

## Candidate Evidence Row

For each readable public pin, preserve:

1. stable candidate and RWI row ids;
2. public pin URL or numeric id;
3. individual local path, SHA-256, dimensions, and capture receipt;
4. section id and exact function;
5. proposed `main_reference` or `supporting_visual_reference`;
6. a plain-language Major, Key Screen, or likely Core-Cut role;
7. observed subject, action/hold, object/environment response;
8. still-camera height/distance/direction/angle, depth, placement, crop and
   negative space;
9. light, color, texture, material, and spatial behavior;
10. bounded source-to-screen transfer and discard boundary;
11. current song, title identity, world, and section dependency;
12. nearest-neighbor difference, mismatch/feasibility risk, and screen
    information lost if removed.

Do not treat captions, keywords, board names, or a function-only paraphrase as
pixel evidence. A proposed main pin must be able to govern a named screen
decision. A support pin must fill or challenge a distinct function rather than
decorate the main candidate.

## Comparison Surface

Build contact sheets with the active World/Still contact-sheet helper and
contract, using contain-fit full images. The label must show candidate id,
section, proposed main/support class, authored role, function, and source
identity. Preserve identical candidate order across the manifest, sheet,
Decision Set, and RWI delta. Split at 16 images or earlier when different
functions need independent comparison.

The worker first inspects each individual image, then the complete sheet, then
reopens detail as needed. A contact sheet is navigation/comparison evidence;
it is never a selected reference, a Pinterest unit, or a generation input.

CDD holds a cohort that merely repeats the same standing/editorial pose, camera
height, or composition with styling-noun substitutions, and holds extra
retained pins that repeat one work, one event or situation, and one visual
grammar while a distinct relevant alternative exists unnamed. Extra
`applied`/`combined` same work+event+grammar units include the named alternative
CDD looked at, or HOLD unless a Founder-exception names the repeat. Scripts check
that this declaration exists. Name pin identity, event/situation, camera height
and direction/angle, composition, and screen function from inspected pixels.
This is contextual creative judgment, not a uniqueness scorer, a fixed
pose-count quota, diversity score, or machine classification rule.

## Closeout Interpretation

There is no fixed discovery or FP-close candidate quota. For each named visual
section, Major, or Core gap, compare only enough readable individual public pins
to make the strongest route, nearest meaningful alternative, source-to-screen
consequence, and material risk professionally decision-ready. Continue while a
named function remains unresolved; stop when additional pins would not change
the Director's decision. Internal FP Close keeps only functionally necessary
`applied` or `combined` survivors, and 02A later binds the smallest useful
per-cut subset.

This adaptive Pinterest candidate policy does not alter the exact-five frame
cardinality of an active one-second Sequence Unit. A Pinterest still cohort and
a moving-source Sequence Unit are different evidence types. Pins fill the
named distinctive still Sequence does not carry. Stop when another pin would
not change the Director's section decision. Do not treat pins as Sequence
Units.
