## Dispatch Packet

Every model dispatch states:

- task and content/run id;
- studio role, objective, active stage, logical dispatcher, and recipient
  director;
- exact owner and one-section default or justified connected two-to-three-section
  pre-02A scope;
- interaction surface, parent lineage, session/reuse policy, and active-owner
  lock;
- Founder epoch, explicit locks, and canonical write authority;
- source paths/SHA-256 and external discovery/paid permission state;
- exact required skills and linked modules, with read-to-EOF and apply
  instructions;
- candidate/output bound and required Anti-Flat evidence;
- exact provider profile and tier: frontier for Overall/CDD, Grok 4.6 High as
  the ordinary worker default, Grok 4.6 Medium for bounded simple research, and
  Luna XHigh only as an explicitly selected optional route with no fallback;
- output path ownership, return shape, validation mode, and stop conditions.

Launch and return record the task id, skill revisions, input digest, result
digest, owner, and runtime/session identity. Every multi-file return exposes one
aggregate manifest with exact child paths and SHA-256 values; the Director
Dispatch Index stores only the pointer, state, review, and next action. A
worker-authored manual skill receipt is not required.

Every dispatched creative worker call, including a provider-resolved post-02A media
lineage, names one reference mode:

- `local_plus_external_discovery` for approved broad local and external search;
- `bound_then_gap_search` for selected evidence first and only named gap or
  challenge search afterward; or
- `bound_only` for an explicit governing lock with no gap search.

It returns inspected exact media or bounded sequences with candidate evidence,
not a text-only concept.

## Validation Modes

- `Explore`: bounded draft scope, source availability, evidence readability,
  and basic shape.
- `Promote`: owner/epoch, input/result digests, source bindings, applicable
  schema, and director review.
- `Execute`: strict hashes, permissions, exact output state, and pixel/playback
  evidence.

Do not use Execute-level downstream validation to gate ordinary exploration.

## Section Parallelism

Parallel work is legal only when:

- pre-02A block scopes or post-02A section scopes are disjoint;
- packet/output paths are disjoint;
- source truth is hash-bound;
- the Overall Director has passed the same whole-video spine and decision epoch;
- each block/section has one owner;
- the coordinator alone merges.

Never exceed the lower provider/runtime capacity. Launch only disjoint,
named-gap pre-02A assignments and disjoint post-02A section owners; queue the
rest and stop once decision-ready evidence closes the named gaps. Do not parallelize multiple
writers against one canonical file. If returned work is waiting for CDD or Edit
Director review, a shared index/board writer is behind, or an owner/path
collision exists, stop launching and apply backpressure even when capacity
remains.

Creative delegation is flat. A worker may use deterministic tools or bounded
provider-native helpers under its exact work package but may not transfer its
logical owner or canonical writer role. An oversized worker returns
`split_required` with exact unowned subscopes, proposed sibling count, disjoint
output paths, shared boundaries, and risk; the recipient director decides.

## Resume

Resume a pre-02A development block from its exact durable checkpoint and source
set. After 02A approval, open a fresh physical production session from the
compact approved one-section checkpoint; never carry a multi-section planning
chat or rejected pool into 02B. After the verified Graph v2 switch, the
post-02A session owns execution through placement and 03V and returns the passed
package only to its exact V-Ci cohort CDD. A section HOLD that exposes an
upstream defect returns the exact affected scope to the matching P3-Ci
checkpoint; that CDD returns a replacement 01/02A shard before
the same section lineage resumes. A session change does not reopen unchanged
creative planning. If source meaning or bytes changed, return to the smallest
owner and invalidate affected dependents.

After all required 03V handoffs pass, Overall opens one fresh Founder-visible
Edit Director task. Edit Director may dispatch disjoint Edit `worker_high` section/chunk
shards, reviews and merges them, and returns final 04/05 truth to Overall. Edit
shards never bypass their director or become canonical final edit truth.

## Pointer-Only Recovery Surfaces

The Director Dispatch Index and scoped views are mechanical pointers over
Department Dispatch attempts. They expose lineage/session identity, bounded
scope, lifecycle state, input/result digests, aggregate-manifest pointers,
review disposition, board links, holds, canonical heads, and next actions. A
multi-file return must expose one aggregate manifest with exact child paths and
SHA-256 values; no index row embeds creative bytes or long prose.

The Director Boot Pack projects only active stage, decision epoch, explicit
locks, open/held tasks, canonical heads, active board cycle, and next actions.
It excludes full transcripts, raw pools, rejected dumps, and unrelated section
artifacts. Index and board manifests have one mechanical writer each and abort
on a source-set digest change. The unified board keeps `discovery`,
`direction_synthesis`, and `fp_final` semantics. Overall alone owns the Founder
conversation and promotion; each CDD owns only its Planning lane or section
cohort, while Edit Director owns the 04 surface.
