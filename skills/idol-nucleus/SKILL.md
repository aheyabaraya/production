# IDOL Song-Backed Creative Core Router

The active MV graph-engineering route does not create `00-creative-nucleus.yaml`. The useful
creative-core work lives in 00A plus Front Planning.

Use this skill only when a request still uses “nucleus” language or when a song
direction must be connected to the active planning route.

## Required Reads

1. `AGENTS.md`
2. `policies/creative-production-constitution.md`
3. `policies/harness-routing-and-sources.md`
4. `wiki/production-system.md`
5. `schemas/song-lock.schema.json`
6. `schemas/front-planning-readiness.schema.json`
7. selected-audio analysis and audio-motion map
8. active 00A song lock
9. `skills/idol-front-planning-director/SKILL.md`

## Route

- If no selected song or manual song direction exists, remain in PRE-00/song
  production.
- If the song exists but 00A is missing, route to the song-production lock.
- If 00A exists, route target, message, title identity, reference connection,
  whole-video progression, and section spine into active Front Planning.
- Never project a second 00 artifact, compatibility shell, or duplicate creative
  spine.

## Quality Boundary

Do not let a short “nucleus” summary replace:

- audience evidence;
- message and audience promise;
- current-title visual package;
- reference research and interpretation;
- whole-video progression;
- section member/scene/reference allocation;
- Founder PASS/HOLD/REJECT.

## Output Boundary

This router authors no artifact. It may identify the missing active owner and
handoff target, but it must not create, update, mirror, or migrate a nucleus
file. Song truth is written only through `idol-song-lock`; target, message,
reference, visual, and whole-video truth are written only through active Front
Planning.
