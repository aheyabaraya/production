# Candidate Set Quality Contract

Use this contract before presenting the three MV concept research sets.

## Founder Research Profile

Unless the Founder explicitly overrides it, deliver:

```text
candidate sets: exactly 3
core messages: 1 per set
main references: 3 per set
derived references: 3 per main / 9 per set
narrative axes: at least 7 per set
required integrated dimensions:
  narrative/relationship
  world/event
  screen/music
```

This is a research audition profile. It is not a downstream creative-readiness
formula and does not constrain song sections, scenes, Core Cuts, or Branch Cuts.

## Complete Set Test

Each set must stand as a plausible full MV candidate before comparison. Include:

- a one-sentence core message;
- the listener situation that makes the message useful;
- a central dramatic question;
- a relationship choice;
- an external event or world pressure;
- an ending choice and aftertaste;
- three main references and nine derived references with relation types;
- at least seven interacting narrative axes;
- a whole-song escalation and release path;
- observable screen and music consequences;
- directorial strengths, weaknesses, feasibility risks, and direct-reference application scope.

Do not submit a logline, reference list, or seven-beat synopsis as a complete
set.

## Whole-Film Story Organization Test

The director must author one complete story for each set before presenting its
reference table. A reader should be able to answer:

- Who occupies the central relationship positions?
- What is the opening state?
- Which event or discovery makes the prior state impossible to maintain?
- How do the relationship, world rule, external event, and recurring object or
  motif pressure one another?
- What escalates because of an earlier action rather than coincidence?
- Which choice becomes irreversible?
- What concrete consequence follows?
- How does the ending change the meaning of the opening?

The story may use nonlinear chronology, multiple viewpoints, associative
images, ambiguity, or an unresolved ending. Those choices must be organized:
state changes, collisions, and consequences still need to be readable.

Do not combine source plots scene by scene. Extract selected mechanics from the
references and compose a new story whose characters, causal chain, world,
climax, and ending belong to the current song.

Every applied or combined reference must map to one exact story or directing
job. References that informed the search but do not belong in the final set
must be marked held or rejected instead of being dumped into the proposal.

## Narrative Axis Test

A narrative axis is a continuing causal or emotional layer. It must include:

```text
axis subject
initial state
pressure or conflict
turn or change
payoff or intentional non-resolution
collision with at least one other axis
audio or song-section anchors
observable screen proof
```

A scene does not become an axis merely because it happens at a different
location. Several scenes may advance one axis, and one scene may collide
several axes.

Useful axis families include relationship, character self-concept, external
incident, world rule, object or motif, time or memory, public/private tension,
ethical choice, rival obligation, collective pressure, and ending consequence.
Use only the families that serve the song.

## Integrated Three-Dimension Test

### Narrative and relationship

State who wants what, what is withheld or misread, which choice changes the
relationship, and what remains unresolved.

### World and event

State the external system, incident, task, deadline, ritual, route, or object
behavior that forces visible decisions. Conversation alone cannot supply all
seven axes.

### Screen and music

State how the relationship and events become visible at audible turns. Include
action or hold, space, camera or edit behavior, and the state change that
survives into the next passage.

All three dimensions must coexist inside every set. Do not assign them as
separate jobs to the three main references.

## Three-Set Difference Test

Compare the candidates on these fields:

| Field | Set A | Set B | Set C |
| --- | --- | --- | --- |
| dramatic question |  |  |  |
| relationship choice |  |  |  |
| external event system |  |  |  |
| information or time structure |  |  |  |
| climax decision |  |  |  |
| ending consequence |  |  |  |
| dominant screen/music grammar |  |  |  |

Revise when two sets can exchange titles, references, or locations without
changing the causal story. A different visual surface is not a different
candidate.

## Message Emergence Test

The message must emerge from the song tension and the researched story
mechanism. Check:

- Which lyric or relationship contradiction created the dramatic question?
- Which source mechanism complicated the obvious interpretation?
- Which story choice proves the message rather than explaining it?
- How does the ending reframe the opening?
- What would be lost if the message were replaced by a generic line about love,
  confidence, farewell, freedom, or memory?

Reject a message that could be pasted unchanged onto all three candidates.

## Screen Proof Test

For every narrative axis, name at least one visible proof:

- body action, gaze, or intentional stillness;
- object transfer, damage, transformation, return, or refusal;
- environment rule or public event;
- blocking or distance change;
- camera viewpoint, route, depth, or repeated geometry;
- edit order, temporal conflict, interruption, or release; and
- the audio cue that makes the change legible.

Poetic intent may remain, but it cannot be the only execution statement.

## Failure Conditions

Do not present the sets when:

- only the main reference or setting changed;
- the same unspoken-goodbye, pursuit, revenge, awakening, or self-love plot was
  paraphrased three times;
- the message was selected first and sources merely justify it afterward;
- seven sequential beats are presented as seven layered axes;
- references are presented before or instead of an organized whole-video story;
- the story is a collage of recognizable source plots rather than a new causal
  composition;
- references are named without exact functions or source relations;
- the world contains no event that changes the relationship;
- the screen plan contains only mood, palette, styling, or locations;
- the music plan contains only section labels or lyric illustration;
- the ending resolves through an unexplained confession or coincidence; or
- production feasibility is used to flatten all three candidates into the same
  safe route.

## Founder-Facing Output Order

Present each set in this order:

1. title;
2. core message;
3. complete whole-video story in natural prose;
4. dramatic question, causal progression, irreversible choice, ending, and
   aftertaste;
5. seven or more interacting narrative axes;
6. three-dimensional set summary;
7. main/derived reference table with dispositions and exact story jobs;
8. whole-song screen/music progression;
9. strengths, weaknesses, risks, and direct-reference application scope.

End with one compact comparison table. Stop for Founder selection,
combination, revision, or rejection. Do not continue into Front Planning.
