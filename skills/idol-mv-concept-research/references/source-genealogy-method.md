# Source Genealogy Method

Use this method to move from a song and an initial reference to auditable
source roots, related content, and current-song directing functions.

## Contents

1. Research objective
2. Source order
3. Relation types
4. Main-reference test
5. Three derived-reference roles
6. Evidence record
7. Function extraction
8. Visual and response evidence
9. Holds and direct-reference scope

## 1. Research Objective

Research the story-generating mechanism behind a reference rather than only
its tone, color, styling, or popularity. The useful chain is:

```text
song tension
-> dramatic question
-> main reference
-> extracted motif or mechanism
-> root, prior, parallel, or later work
-> exact current-song function
-> screen consequence and direct-reference application scope
```

The chain may move backward to a myth, folktale, classic, play, novel, manga,
or original screenplay and sideways or forward to later adaptations and formal
analogues. Do not force every work into an ancient root.

## 2. Source Order

Use this order when public research is authorized:

1. Inspect Founder-provided and local sources first.
2. Use NamuWiki, Wikipedia, or an equivalent encyclopedia to establish search
   terms, alternate titles, characters, events, motifs, and claimed originals.
3. Open the original text, official synopsis, creator interview, distributor
   page, production note, or another authoritative source.
4. Confirm the exact event and character relationship relevant to the current
   song.
5. Search related adaptations, reinterpretations, and formal analogues.
6. Inspect actual visual material for screen-function claims.
7. Do not query, search, open, download, capture, play, inspect, analyze,
   register, cite, or otherwise use an AMV, MAD, or fan edit unless exact
   current-task Founder permission names the source identity/URL, purpose, and
   allowed action. A supplied link/file is not permission, and rhythm-analysis
   permission does not authorize scene binding. Leave incidental results
   unopened; if indispensable, return `founder_permission_missing`.

An encyclopedia is a map, not the final proof. A response edit is a reception
signal only when explicitly permitted; it is never original-story context.

## 3. Relation Types

Assign one honest relation type to every derived reference:

- `original_source`: the direct text or work adapted by the main reference;
- `direct_adaptation`: a credited adaptation of the same source;
- `documented_influence`: influence stated by a creator or authoritative
  production source;
- `motif_lineage`: a shared mythic, folkloric, literary, or cultural motif;
- `narrative_analogue`: a similar relationship or conflict mechanism without
  proven lineage;
- `formal_analogue`: a similar time, viewpoint, structure, or narration form;
- `screen_analogue`: a useful camera, edit, blocking, object, or spatial
  function without a story-lineage claim;
- `response_pattern`: audience-selection evidence from edits or recurring
  excerpt use.

Never upgrade `analogue` to `influence`. When relation evidence is uncertain,
record `unverified_candidate` and keep researching or hold it.

## 4. Main-Reference Test

A main reference should answer several of these questions:

- What relationship becomes unstable?
- What choice changes ownership, trust, memory, identity, or separation?
- Which external incident or world rule prevents the characters from remaining
  static?
- What temporal, viewpoint, or information structure can carry a full song?
- Which repeated gesture, object, place, or system can change meaning?
- What ending consequence remains after the plot action stops?
- Can the reference generate observable screen behavior tied to music?

Reject a main reference that contributes only general mood or current visual
fashion unless the set already has a strong story engine and that bounded
screen function is genuinely missing.

## 5. Three Derived-Reference Roles

Research three derived references for every main reference. Across the three,
seek a useful spread of:

- source or root context;
- a later or parallel narrative transformation; and
- an audiovisual or formal execution reference.

This is a diversity target, not permission to invent false ancestry. A main
reference may have no meaningful mythic root. In that case, use an original
text, documented predecessor, narrative analogue, formal analogue, or screen
analogue and label it accurately.

Do not count three titles that all repeat the same relationship, space, event,
and screen answer. Each derived source must add context, contradiction, or a
new executable function.

## 6. Evidence Record

Keep each source auditable in the working research:

```text
Source identity:
Title / creator / year when known:
URL or local path:
Relation type:
Relevant character, event, motif, or sequence:
Context evidence:
Original or official verification:
Actual visual inspection evidence, when applicable:
Current-song function:
Confidence / unknown:
```

Do not invent year, creator, plot, character, or influence facts. Distinguish
observation, sourced fact, and directorial inference.

## 7. Function Extraction

For every selected main reference, and for each derivative that materially
shapes the proposal, extract functions across these dimensions:

### Narrative and relationship

- desire, withholding, misunderstanding, loyalty, rivalry, authorship, memory,
  separation, exchange, or ethical choice;
- which person changes and who pays the consequence;
- what information or action alters the relation.

### World and event

- deadline, ritual, route, institution, game, translation system, spatial rule,
  object behavior, public incident, or irreversible event;
- what prevents passive conversation from carrying the whole video;
- how the external event collides with the relationship.

### Screen and music

- body action or intentional hold;
- object or environment change;
- camera height, distance, direction, depth, route, or stillness;
- edit order, repeated viewpoint, temporal reversal, rhythmic interruption, or
  release;
- which audible cue makes the screen change readable.

Do not divide the three dimensions into one-reference-per-role. Judge the three
main references as an integrated set and allow each source to contribute to
multiple dimensions.

After extraction, disposition every researched reference as `applied`,
`combined`, `held`, or `rejected`. For `applied` or `combined`, name the exact
organized-story job it serves: relationship turn, causal incident, world rule,
object recurrence, temporal structure, climax choice, ending consequence,
camera route, or edit/music behavior. A title without a story assignment is not
an application. `held` and `rejected` sources remain research evidence and must
not be forced into the narrative merely to satisfy the reference count.

## 8. Visual And Response Evidence

For an image, inspect the actual file or stable source image. For video, inspect
the selected frame, time-bounded segment, or ordered start/change/peak/end
sequence. A whole contact sheet is navigation evidence, not a selected visual
unit.

Use audience edits only after source context is known. Record what they show:

- a moment repeatedly selected;
- a relationship beat compressed into a hook;
- a gesture or collision used as a transition;
- a scene that survives without exposition; or
- a recurring emotional payoff.

Do not infer broad audience preference, commercial success, or source meaning
from one edit.

## 9. Holds And Direct-Reference Scope

Hold a source when its title, original identity, scene context, or relation type
cannot be established well enough to avoid a wrong reference.

For every applied or combined reference, state:

- what is preserved;
- what is transformed for the selected song and members;
- any explicit Founder replacement/discard boundary; and
- how the current song changes the ending or consequence.

The goal is not distance for its own sake. A selected visual reference may carry
its actual camera, composition, crop, body route, and scene grammar directly.
Rebuild only the elements outside the selected surface or those explicitly
changed for the current song.
