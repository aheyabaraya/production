# X Posting Template

X is Loom’s **first public channel** in any multi-platform batch. This skill
writes English copy and attachment plans only. It does not post, schedule,
draft on X, or touch credentials.

**Operating thesis (2026-08 live check):** X rewards (1) strong screen units
with light copy, (2) remixable prompt gifts, and (3) occasional build proof —
not a full brand+stack+link essay on every root. Loom’s feed is fed from
**CF/MV work already in production**: finals, derived clips, member stills.

## Read / Write Contract

Read this `SKILL.md` fully before authoring. Also read `AGENTS.md` and
`wiki/social-automation-system.md`. For CF work, read `cf/AGENTS.md` and the
owning CF publishing skill. For brand-core wording, read the relevant
`business-marketing/brand-management/**` and run-locked message sources before
writing poetic or member lines.

**This file is the full X posting template.** Structure, paste shapes, prompt
policy, cadence, and field evidence live here — there is no separate
authoring-detail reference to open for normal drafting.

Allowed output is copy and an attachment plan inside the owning run's
social/publishing artifact. Posting, scheduling, credential access, API calls,
Founder approval, and canonical creative-stage mutation are forbidden outputs.

| Pillar | On X |

Idol presence is **not** a separate campaign brand. It is the default feed.
Graph Engineering is **evidence**, not a daily about-page.

## Content inventory (what to post)

Fed from work Loom already makes.

| Type | Source | Default intensity |
| --- | --- | --- |
| **work_root** | CF final, MV cutdown 8–20s, occasional master highlight | 1–2 |
| **derived_clip** | Hook 2–8s, member beat, object/world beat from that work | 0–1 |
| **member_still** | Title member visual, board still, portrait (2–4 images OK) | 0–1 |
| **craft_gift** | Same asset + public remixable prompt thread | 2 |
| **harness_proof** | boards → still → motion → edit evidence (≤15–30s or still sequence) | 3 |

**Cadence (local heuristic, not a platform guarantee):**

- About **2–3 posts/day** is allowed when **media units differ** (not the same
  full clip thrice).
- Prefer **2–4 hour spacing**; avoid five-minute dumps of three long threads.
- Weekly mix target: **~70–80%** stills/short clips · **~10–15%** work roots ·
  **~5–10%** craft_gift / harness_proof.
- Never repost the identical full cut with only a new date.

## Graph Engineering intensity (0–3)

Pick **one** intensity per root. Do not max every post.

| Level | When | Root includes | Root excludes |
| --- | --- | --- | --- |
| **0** | Most member stills / hooks | Hook and/or member intro + `AI-made with Grok and GPT.` + tags | Stack, Signal Deck, `workflow 👇`, long claim text |
| **1** | Many derived clips / light tool magnet | Level 0 + **one** product name (`Grok Imagine` or `GPT image`) | Full stack, Signal Deck |
| **2** | Work roots; a few times per week | Short stack `GPT image → Grok Imagine → Grok Build` + disclosure; CF claim guard if needed | Prefer Signal Deck in reply; optional `prompt in thread` |
| **3** | 0–2×/week or ≤1 per work | Visible pipeline proof + thin graph-engineering line; optional Codex directing line | Essay about “we are an agent graph”; put Signal Deck in **reply** |

Agent/builder reach comes from **accumulated level 2–3**, not from putting the
full stack on level 0.

## Member intro rule (stills and clips)

Whenever a **named member is meaningfully visible**, include **one plain English
line**: who + what they are doing / holding now (state, duty, temperature) —
not a long profile bio.

```text
{MEMBER} — {one-line “doing now” from brand card or run lock}
```

Examples of shape (do not copy nouns into unrelated posts):

```text
Seorin — holding the last look before the cut.
Lua on desk light duty — still, not posing.
```

Source: brand-core member temperature cards and/or run-locked on-screen action.
Do not invent biography, powers, or world rules.

Optional poetic half-line may sit above or below; **intro is mandatory** when
the post is member-led.

## Subject frame (after message)

`subject_frame` is a **one-line content-kind line**: genre, form, product class,
occasion, or mood that names **what kind of screen this is**, grounded only in
what the approved media actually shows (or the run’s CF subject / track form
lock). It is **not** the message (what the viewer should receive), not a brand
claim, and not a world-bible dump.

```text
{subject_frame — category language, screen-true, one line}
```

| When | Rule |
| --- | --- |
| **CF work_root** | **Required** when the work has a clear advertised subject/category |
| **MV work_root** | **Required** when track form/genre is part of the public pitch |
| **derived_clip** | **Recommended** if the beat still reads as that category; else omit |
| **member_still** intensity 0 | **Optional** — keep light; tags may carry category alone |
| **craft_gift / harness_proof** | Optional; do not bury the gift/proof line |

**Do:** category language only — e.g. battle-royale mood game film, quiet desk
cable-management CF, eyewear fashion film, chorus hook cut.
**Do not:** official partnership claims, brand-as-owner tags in prose, inventing
genre not on screen. Spec CF still needs the separate claim guard when a real
brand is readable.

Pair the same category words into hashtags when Non-X or when X uses tags
(shared rule with `idol-social-metadata-upload` subject/product-class tags).

Shape examples (grammar only — rewrite from current locks/media):

```text
Battle-royale mood game film — drop energy, no official tie-in.
Quiet desk cable-management CF — one click, closed weave.
Chorus-hook idol cut — face-forward temperature, not full MV.
```

## Primary paste shapes by type

### A. member_still (default daily) — intensity 0–1

Media: 1–4 stills. No video+image on the same post.

```text
{MEMBER} — {one-line doing now}

{optional half-line poetic temperature}
{optional subject_frame if category is not obvious from still alone}

AI-made with Grok and GPT.
{optional: GPT image.}
#Loom #{Member}
```

### B. derived_clip — intensity 0–1

Media: one short clip (prefer 3–12s). Prefer a **different beat** than the work
root.

```text
{MEMBER or beat} — {one-line doing now if member-led}
from {Track or CF}
{optional/recommended subject_frame}

AI-made with Grok and GPT.
{optional: Grok Imagine.}
#Loom #{TrackOrMember optional}
```

### C. work_root (CF / MV) — intensity 1–2

Media: CF final or MV 8–20s cutdown (full master only if Founder locks).

```text
{poetic hook from brand/run lock}

{optional message one-liner}
{subject_frame — required when CF/category-led or track form is pitched}

AI-made with Grok and GPT.
GPT image → Grok Imagine → Grok Build
#Loom #{TrackOrCF}
```

**CF claim guard** when a real brand is visually readable:

```text
{poetic premise / member line}

{subject_frame — category language only}
Spec concept. Not an official {Brand} campaign.

AI-made with Grok and GPT.
GPT image → Grok Imagine → Grok Build
#Loom
```

Signal Deck: **reply** (not root) unless Founder explicitly wants root link.

### D. craft_gift — intensity 2 (optional thread)

Root: strong still or clip. Prompt must be **public-remixable** (see Prompt
policy).

```text
{MEMBER or scene} — {one-line doing now if member-led}
{optional: one-line what you see}

AI-made with Grok and GPT.
{GPT image | Grok Imagine} · prompt below 🧵
#Loom #{Member optional}
```

**reply_1** (image gift) or **reply_1** (video gift) — exactly one primary gift
prompt per thread unless Founder locks both:

```text
1️⃣ Image prompt
{public-remixable image prompt for one still}

GPT image.
```

```text
1️⃣ Video prompt
{public-remixable video prompt; short timed beats OK}

Grok Imagine.
```

**reply_2** (optional archive):

```text
2️⃣ Loom
GPT image → Grok Imagine → Grok Build
https://loom-signal-deck.vercel.app/
```

### E. harness_proof — intensity 3 (rare)

Root: short pipeline evidence (boards → motion, or three stills ordered). Not a
text essay.

```text
{one line: what the screen proves}

Directed in Codex. Boards on GPT image. Motion on Grok Imagine. Routed on Grok Build.
AI-made with Grok and GPT.
#Loom
```

Reply: Signal Deck + optional thin restack. No stage IDs.

### F. Kiki-class process film thread (only when intensity ≥ 2 and prompts public)

Use when a Founder-locked process drop needs boards + one image gift + one
video gift. **Not** the default for every CF/MV.

```text
ROOT     video + hook (+ member intro if member-led) + short stack or product line + prompt CTA
         (no Signal Deck on root)
REPLY 1  boards 2–3 stills + ONE public-remixable image prompt
REPLY 2  public-remixable video prompt
REPLY 3  optional stack + Signal Deck URL
```

Root paste:

```text
{poetic idol / scene / CF hook}
{member intro if member-led}

AI-made with Grok and GPT.
GPT image → Grok Imagine → Grok Build

prompt in thread 🧵
#Loom #{TrackOrMember optional}
```

## Prompt policy

| Kind | Policy |
| --- | --- |
| Public image/video prompt | Only when `template_type` is craft_gift or process thread; **remixable** |
| Image full prompt | At most **one** primary image gift per thread |
| Video full prompt | When motion gift is offered; public-safe timed beats OK |
| Internal packets | Never (`02A`/`02B`, run paths, identity packs, full exclusion dumps) |
| Sanitization | Strip internal IDs, private paths, unapproved reference-identity instructions, board-lock “must not” novels |
| Remixable means | Another creator could regenerate a similar still/clip without Loom’s private storyboard law |

If the only available text is an internal execution lock, **do not** post it as
a prompt gift — post as level 0–1 screen only.

## Copy source and tone

1. **Member intro** — plain; brand card or on-screen lock.
2. **Poetic line** — elevated English; not checklist voice as the only line.
3. **Source lock** — brand core and/or run-locked message (`00A`, Front
   Planning, CF strategy, Founder lock).
4. **Do not invent** new promises, world rules, or participation claims.
5. **Message on X** — optional if hook + intro already carry intent.
6. **Subject frame** — category/form/mood after message when CF or form-led;
   screen-true only; never a fake official brand claim.
7. **Stack / tools** — exact product names (search magnets).

Record `copy_source_refs` in the publishing-plan row when known (paths or field
ids only — not secret material).

## Shared rules

1. **English only.**
2. **One idea per root** — one member moment, one beat, or one work drop.
3. **Signal Deck** — default **not on level 0–1 root**; reply/bio/level-3.
4. **Tags:** 0–3 (`#Loom` + optional track/member). No tool-hashtag walls.
5. **Analytics:** `analysis_scope: scheduler_whitelist` when measured.
6. **Forbidden without Founder:** post/schedule/API, secrets, false brand claims.
7. **No Elon / RT bait / fake partnership.**
8. **No video+image on the same post.**
