# Active 02A Founder Storyboard Handoff

The 02A preview is a review projection of canonical 02A v3.0, not separate
creative truth.

## Layout

Use active `idol-html-review-board.v12` by appending this review cycle to the
same `RUN/review/founder-workbench.html`. Never create a separate 02A preview
HTML. The Core-Cut visual row retains the fixed left member face/styling rail
and the right reference row; ordered Branch-Cut children extend below it.
Media are automatically indexed `01 / N`. More than four desktop reference
panels remain in one left/right carousel row with range status, while mobile
shows one slot. Clicking a thumbnail enlarges it and clicking the enlarged
image again closes it.

Read in this order:

1. complete PRE-00-rooted full-storyline lineage, beginning with the immutable
   original and then the active full-text version and its reference receipts;
2. target and message summary;
3. whole-video and section-flow summary as a navigation index;
4. exact source-hashed Founder Alignment Storyline from whole video through the
   current section and planning cut;
5. section;
6. core cut; and
7. ordered branch cuts with their 02A storyline expansion.

The Founder must be able to judge the MV flow before image generation.

## Core-Cut Card

Show:

- audio/section cue;
- screen job;
- intended first-time target-viewer read;
- governing event/action/effect/condition and space;
- members/objects;
- reference grammar;
- camera position in the space, governing axis/screen direction, and full
  anchor-view geometry/composition;
- ordered Branch Cut camera roles, protected continuity, broad allowed
  variation, and forbidden collapse;
- choreography policy;
- entry/exit continuity;
- why the next governing event follows, or the final section exit/afterimage
  reason;
- ordered branch-cut count, branching logic, and reason.

Show explicitly that the anchor is a coordinate rather than a default frame.
The Founder should be able to see why each Branch Cut preserves or departs from
it; broad height, distance, direction, angle, axis, depth, placement, crop,
lens, and viewpoint variation remains available when it adds information.

## Branch-Cut Card

Show:

- derivation from the parent core event;
- exact planning-cut storyline source and the observable 02A expansion added
  for this Branch Cut;
- distinct screen information or directorial contribution;
- whether that contribution is direct message/empathy evidence or which named
  supporting job makes later evidence legible;
- visible state;
- current-title member visual actually selected when meaningful;
- governing scene/sequence reference and any supporting-component reference in
  combined order;
- still-camera geometry;
- composition/crop/depth;
- action/hold;
- previous/next branch relation;
- expected output ownership.

Do not force a member face into the preview when the branch cut is back,
silhouette, world, object, environment, or system led.

## Decision

Every decision uses PASS, HOLD, or REJECT and declares:

- section id;
- core-cut id when present;
- branch-cut id when present;
- matching revision scope;
- canonical source field references.

## Patch Routing

- branch-cut card: exact 02A branch cut;
- Official Core card: exact immutable 01 Official Core carried by 02A without mutation;
- section card: 01 section;
- target/message/title/member allocation: Front Planning;
- pixel-only defect after generation: exact image, not 02A.

The intake must not trigger an all-film rewrite for a local correction.
