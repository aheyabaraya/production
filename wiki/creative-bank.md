# Creative Bank

The creative bank is a retrieval layer, not production truth. Use it to avoid
forgetting useful functions and to prevent repeated attempts under new labels.

The wiki should only link to bank locations and summarize retrieval rules. Leave
full bank cards in the owning bank folder; read/search that folder only when the
bank is relevant to the current task.

## Main Bank

```text
creative-bank/
```

Stores route ideas, hook problems, motion grammar, choreography phrases, camera
movement, gaze/expression, formation, edit rhythm, and later promoted reusable
patterns.

## Message Hook Bank

```text
creative-bank/message-hooks/
```

Stores message functions, hook mechanics, semantic keys, and message-hook
combinations separately from the main bank. PRE-00 should search this bank
before proposing a route and write new combinations here before reuse.

Layering:

```text
idea-vault -> candidates -> promoted
```

Promotion still requires completed-master validation and founder review.
