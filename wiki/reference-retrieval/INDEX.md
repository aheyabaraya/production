# Reference Scene And Sequence Retrieval Index

This is an analysis-first lookup surface. The reusable payload is the linked
source-owned description of **who or what is visible, where the event happens,
what happens in order, and how selected still anchors are photographed**.
Purpose class and reusable function are secondary lookup aids.

## Ready Contract

A unit is ready for creative reuse only when its linked analysis supplies:

- a single still or selected scene anchor: one complete nested 02B-shaped
  source observation;
- a contact, frame, or sequence sheet: Layer A `Sequence flow observation`
  plus Layer B nested observations for every selected anchor cell;
- exact source/time locator, inspected evidence paths and SHA-256, uncertainty,
  and preserve/transform/reject boundaries.

The canonical field tree, leaf jobs, and good/bad examples live only in
`skills/idol-front-planning-director/references/director-operating-contract.md`
under top-level H2 `## 02B-Shaped Source Observation` (file Contents → that
section; Lane 1/2 and examples are H3 under it). Receipt bind/reopen rules stay
in the same file under `## Reference Interpretation Checkpoint`. Do not
duplicate that teaching block here. `candidate_for_reuse`, a purpose class, or a
function summary never proves analysis readiness or Founder PASS. Incomplete Layer A/B or nested still means HOLD so 02B/03V cannot re-consume abstract function text as if it were screen observation.

## Primary Projection Order

When the analyses are rebuilt, project each index row in this order:

1. scene/sequence description: who or what, where, and visible event or hold;
2. source identity, exact time range, and evidence pointer;
3. analysis state and source-owned analysis pointer;
4. sequence-flow and selected-anchor readiness;
5. purpose classes and reusable function;
6. reuse/direct-use state and unit id.

No script may fill missing observation fields from a purpose label or template.
Missing Layer A/Layer B truth stays `HOLD` until a human or assigned model
re-analyzes the actual evidence.
