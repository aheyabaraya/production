# Standing Constraint Index

This page is the terminology owner for graph-engineering constraints. The machine index is
`automation/harness-standing-constraint-catalog.yaml`. The catalog points at
owners. It does not copy their rules.

## Grades

- `standing_constraint`: shared law. Lives in `AGENTS.md`, an activated policy,
  an active schema HOLD, or a Founder `stop_doing` row. Receivers load the
  owner, not a growing memo file.
- `run_followup`: this-run learning. Lives in
  `RUN/review/harness-improvement-review.yaml`. Resolving the run does not
  promote the row.
- `founder_promotion`: Founder moves a repeated `run_followup` into a
  `standing_constraint` owner after an overfit guard.

## Not in this system

- `CONSTRAINTS.md` as a second always-on rulebook
- automatic skill save after a verify pass
- weekly swarm as graph-engineering mutation
- helper count as creative quality
- v18 Front Planning admission on frozen COLOR STAY v17 bytes

## Four consumed graph gaps

1. Helper returns need a `helper_consumption_receipt` before they count as
   graph edges. Department dispatch requires bound consume/reject/hold
   receipts when native helpers were used.
2. `run_followup` is opened on material helper recurrence and reviewed by
   Founder; it is not auto-written into skills. The sidecar lives at
   `RUN/review/harness-improvement-review.yaml`.
3. `role_context_pack` remains the current-node projection. Optional
   `live_run_state` carries open HOLD ids, consumed helper ids, and the
   run_followup path. When that path resolves to a valid v3 sidecar, the pack
   additionally carries only matching `founder_quality_context` compact rows:
   reason summary, recurrence count, bounded decision/review signals, source
   sidecar pointer/digest, and no raw Founder wording. The field is advisory
   and is not in `required[]`.
4. Local and Pairwise review belong to CDD. Global review belongs to Overall.
   New Front Planning must declare those nodes. COLOR STAY v17 admission is
   unchanged and stays skipped without `--admission-graph`.

## Line-count rule

When two instruction surfaces repeat the same stop-doing, keep the stronger
owner and replace the copy with a pointer to this index plus the owner path.
Do not split a unique quality instruction to chase a word target.
